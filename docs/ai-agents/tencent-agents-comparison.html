🎯 各产品的"擅长/不擅长" · 一句话定位

产品 ✅ 最擅长做 ❌ 别让它做
🦞 OpenClaw
开源框架		 研究 Agent 底层、需要完全控制、本地隐私优先、想基于它做二次开发 开箱即用的业务场景、IM/移动端、企业级安全合规
💼 WorkBuddy
腾讯自研		 通用办公：报告/PPT/数据清洗/文件整理；移动远控（ClawBot）；个人/家庭场景 深度编码（不如 CodeBuddy）；连腾讯内网（无 OA 身份）
💻 CodeBuddy
腾讯自研		 国区日常编码：IDE 深集成、多文件 Craft、单测、评审、commit 非编码场景（PPT/数据分析不行）；公司内部代码（公网版红线）
🗄️ Hermes Agent
垂直 AI DBA		 腾讯云数据库运维：慢查询、索引优化、监控告警、自动 SOP、持续学习业务 数据库以外的一切；非腾讯云用户
🟣 Claude Code
海外 Anthropic		 极限长任务：1M 上下文、Checkpoint 回滚、长链 Agent 工作流、学习前沿范式 国区重要项目（数据出境）；连腾讯生态；预算敏感（$6/天）

⚠️ 避坑清单

  1. ❌ 不要把 OpenClaw 当腾讯产品 — 它是奥地利程序员的开源框架
  2. ❌ 不要把公司内部代码/文档上传到公网版 WorkBuddy/CodeBuddy/Claude Code
  3. ❌ 不要以为"腾讯文档连接器"能读公司内部文档（实测走微信号）
  4. ❌ 不要拿 CodeBuddy 当 WorkBuddy 用（coding 之外偏弱）
  5. ❌ 不要在国区重要项目主用 Claude Code（数据出境 + 网络不稳）
  6. ❌ 不要把 Hermes Agent 当通用 Agent 用（DB 场景最深，其他场景未成熟）
  7. ✅ 新用户领 WorkBuddy 5000 Credits + 10 款技能包（30 天有效）
  8. ✅ 腾讯员工账号自带旗舰权益 — 别浪费
  9. ✅ Claude Code 平均 $6/天，心里有数
